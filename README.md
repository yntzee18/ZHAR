# ЖАР — баня на дровах

Лендинг банного комплекса с онлайн-бронированием. Прокрутка страницы проводит гостя через банный вечер: жар, купель, отдых. В конце живая форма брони с расчётом цены, готовая к подключению CRM.

## Файлы

| Файл | Что это |
| --- | --- |
| `index.html` | Сайт целиком: разметка, стили, скрипты и шрифты в одном файле |
| `CRM.md` | Как подключить CRM, загрузить занятые часы и что приходит в брони |
| `privacy.html` | Шаблон политики обработки персональных данных |
| `consent.html` | Шаблон согласия на обработку персональных данных |

## Что на странице

- **Первый экран:** огромное слово «ЖАР» с маревом от жара, тлеющие угли, ключевые цифры.
- **«Как проходит вечер»:** закреплённая секция. При прокрутке жар 85° сменяется поднимающейся ледяной водой +8° с живой волной, а затем тёплым отдыхом 24°.
- **Парные:** температура и влажность трёх парных на одной шкале.
- **Пармейстер:** программы парения, при наведении падает дубовый лист.
- **Цены:** тарифы и допуслуги.
- **Чайная:** меню с паром над чашкой.
- **Вопросы:** плавно раскрывающиеся ответы.
- **Бронирование:**
  - дата, время, длительность, гости, допуслуги;
  - живой расчёт суммы с учётом тарифа до и после 17:00;
  - искры после отправки.
- **Пар на всю страницу** густеет или тает вместе с температурой раздела на экране. Градусник в шапке, на широких экранах ещё и справа.

## Технические детали

- Без сборки и зависимостей. Шрифты Alumni Sans, Commissioner и Martian Mono встроены в файл (лицензия SIL OFL). Сайт не обращается к внешним серверам.
- Работает на телефоне: всё в одну колонку, горизонтальной прокрутки нет, лента дат листается пальцем.
- Если в системе включено «уменьшить движение», анимации отключаются, а закреплённая секция превращается в три обычных блока.
- Можно пройти с клавиатуры: фокус видно, после перерисовки кнопок он не сбивается.

## Запуск

Откройте `index.html` в браузере или загрузите папку на хостинг. Для GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

## Что поменять под свою баню

1. **Настройки в блоке `CONFIG`** в начале `<script>`: адрес CRM, занятые часы, ссылки на документы, тарифы, часы работы, гости, допуслуги. Все поля описаны в `CRM.md`.
2. **Тексты, адрес, цены в разделе «Цены»,** программы пармейстера и меню чайной правятся прямо в HTML.
3. **Документы.** Заполните `privacy.html` и `consent.html` и укажите их в `CONFIG`.

## Ограничения

- Оплата на сайте не принимается.
- Пока не указан `busyUrl`, занятость часов условная, для демо.
- Пока не указан `webhookUrl`, брони никуда не отправляются.
- Баня, адрес и цены вымышленные.
